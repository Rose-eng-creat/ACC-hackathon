# 🍫 无痛学习 AI 伴侣 (AI Study Companion)

> ACC 2026 黑客松参赛作品。一款基于大模型的浏览器插件，让知识如巧克力般丝滑入脑。

## 💡 项目背景
在 B站/YouTube 学习时，我们常面临“看完就忘”、“遇到专业名词看不懂”的痛点。本项目通过浏览器插件直接读取当前页面，一键调用 AI 辅助学习，提供学前分析、学中提问及复习推荐功能。

## 🛠️ 技术架构演进（敏捷重构）
本项目在黑客松冲刺阶段经历了敏捷重构：
- **初期（MVP验证）**：采用 `Node.js + Express` 搭建本地后端，成功验证了大模型 API 调用与前后端数据交互的可行性。
- **终期（极速体验版）**：为了保证现场路演的极致稳定性和零延迟，团队果断进行架构优化，去掉了本地后端的重依赖，将核心请求逻辑内聚至前端插件中，并新增了 `视频分析、视频推荐、复习优化` 等功能，极大提升了用户体验。

## ✨ 核心功能
- **学前分析**：提取当前页面内容，调用大模型进行知识点拆解。
- **学中提问**：呼出弹窗直接提问，AI 用大白话打比方为你解答。
- **智能推荐/检索**：`自动根据你对知识的掌握情况为你推送更适合你的相关视频`。

作为 AI 产品经理与核心逻辑开发，我主要完成了：

2. **Prompt 工程与体验设计**：调优大模型 Prompt，强制 AI 输出大白话比喻，极大地降低了用户的理解门槛。
